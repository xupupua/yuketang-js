# yuketang-js
雨课堂油猴自动观看

> **当前状态：实验版。** 已知 1.4 版在实际雨课堂页面不能可靠地自动设置倍速；如需倍速，请在视频播放器自带菜单中手动选择。自动切集和课程完成度也请以实际页面验证结果为准。

## 文件

- [雨课堂助手脚本](yuketang-helper.user.js)
- [Tampermonkey 安装与使用教程](docs/油猴Tampermonkey使用教程.md)

## 安装

1. 在浏览器安装并启用 Tampermonkey（篡改猴）。
2. [打开脚本安装链接](https://raw.githubusercontent.com/xupupua/yuketang-js/main/yuketang-helper.user.js)，在 Tampermonkey 安装页面确认安装。若没有出现安装页面，可按教程复制脚本到新建的油猴脚本并保存。
3. 打开雨课堂的 `ai-workspace` 视频页面并刷新，在助手面板中启动。

脚本可能随雨课堂网页更新而失效；平台记录的学习进度请以课程页面显示为准。
