# 油猴（Tampermonkey）新手使用教程

油猴通常指 **Tampermonkey（篡改猴）**，它是一个浏览器扩展，可以在指定网页运行“用户脚本”。例如，脚本可以为网页添加按钮、调整页面样式，或者提供辅助操作功能。

本教程以 **Windows 版 Google Chrome** 为例。其他浏览器的基本步骤类似，菜单名称可能不同。

## 一、安装 Tampermonkey

1. 打开 Chrome，进入 [Chrome 网上应用店](https://chromewebstore.google.com/)。
2. 搜索 **Tampermonkey**。
3. 核对扩展名称和发布者信息，打开扩展详情页。
4. 点击 **添加至 Chrome**，在浏览器弹窗中确认添加。
5. 安装后，点击 Chrome 右上角的 **扩展程序图标**（拼图形状），可以将 Tampermonkey 固定到工具栏，方便以后打开。

如果脚本无法运行，可以进入 Chrome 的 **扩展程序 → 管理扩展程序 → Tampermonkey → 详细信息**，检查扩展是否启用。某些 Chrome 版本还会显示 **“允许用户脚本”** 开关；如果有这个开关，需要将它打开。不同版本浏览器的界面可能略有不同。

## 二、认识管理面板

1. 点击浏览器工具栏中的 **Tampermonkey** 图标。
2. 选择 **管理面板**（有时显示为 Dashboard）。
3. 在脚本列表中，可以查看已安装脚本的名称、版本和启用状态。

不同版本的 Tampermonkey 界面可能略有区别，但通常都能找到以下功能：

| 功能 | 作用 |
| --- | --- |
| 新建脚本 | 自己粘贴或编写脚本。 |
| 启用 / 禁用 | 控制某个脚本是否运行。 |
| 编辑 | 查看和修改脚本内容。 |
| 删除 | 卸载不再需要的脚本。 |
| 更新 | 在脚本支持更新时检查或应用更新。 |

## 三、通过链接安装脚本

当可信来源提供脚本安装链接时，通常可以这样操作：

1. 点击脚本的安装链接。
2. Tampermonkey 打开安装页面，并显示脚本名称、版本及代码。
3. 查看脚本作用的网站范围和所需权限。
4. 确认后点击 **安装**。
5. 打开脚本对应的网站，并刷新页面。
6. 再次点击 Tampermonkey 图标，查看当前页面是否识别到了该脚本。

安装前建议先阅读脚本说明和代码，并确认来源可信。脚本可能读取或修改它被允许访问的网页内容。

## 四、手动粘贴代码安装脚本

如果别人提供的是一段代码，而不是安装链接：

1. 点击 Tampermonkey 图标，选择 **添加新脚本**；也可以在管理面板点击 **加号**。
2. 在打开的编辑器中按 **Ctrl+A**，选中默认内容。
3. 把需要安装的完整脚本代码粘贴进去。
4. 按 **Ctrl+S** 保存。
5. 回到管理面板，确认新脚本已出现在列表中，并且处于启用状态。
6. 打开脚本指定的网站，刷新页面。

脚本通常以 `// ==UserScript==` 开头，并以 `// ==/UserScript==` 结束脚本信息区。粘贴时不要漏掉这些内容。

## 五、从 `.user.js` 文件安装

拿到一个以 `.user.js` 结尾的文件时，可以用文本编辑器打开它，复制全部代码，再按照上一节的方法粘贴到 Tampermonkey 编辑器并保存。

有些浏览器环境支持直接打开脚本文件后进入安装流程；如果没有出现 Tampermonkey 安装界面，使用“打开文件 → 复制全部代码 → 新建脚本并粘贴”的方法即可。

## 六、自己创建第一个测试脚本

下面的示例只在 `https://example.com/` 页面右下角添加一行提示，不会上传数据，适合熟悉安装流程。

### 1. 新建脚本并粘贴代码

打开 **Tampermonkey → 添加新脚本**，删除默认内容，粘贴：

```javascript
// ==UserScript==
// @name         我的第一个测试脚本
// @namespace    example-tampermonkey-tutorial
// @version      1.0.0
// @description  在示例网站显示一条提示
// @match        https://example.com/*
// @run-at       document-idle
// @grant        none
// ==/UserScript==

(function () {
  'use strict';

  const notice = document.createElement('div');
  notice.textContent = '油猴脚本已运行';
  notice.style.cssText = `
    position: fixed;
    right: 20px;
    bottom: 20px;
    z-index: 999999;
    padding: 12px 16px;
    color: white;
    background: #2563eb;
    border-radius: 8px;
    font: 14px sans-serif;
  `;

  document.body.appendChild(notice);
})();
```

### 2. 保存并验证

1. 按 **Ctrl+S** 保存。
2. 打开 [example.com](https://example.com/)，如已打开则刷新页面。
3. 页面右下角出现“油猴脚本已运行”，说明示例脚本生效。

这个示例的 `@match` 只匹配 `example.com`，所以打开其他网站时不会显示提示。

## 七、看懂脚本开头的设置

```javascript
// ==UserScript==
// @name         我的脚本
// @namespace    my-example-script
// @version      1.0.0
// @description  脚本说明
// @match        https://example.com/*
// @run-at       document-idle
// @grant        none
// ==/UserScript==
```

| 设置 | 含义 |
| --- | --- |
| `@name` | 脚本显示的名称。 |
| `@namespace` | 帮助标识脚本，通常和名称一起用于识别。 |
| `@version` | 脚本版本号。 |
| `@description` | 简短说明脚本用途。 |
| `@match` | 决定脚本在哪些网页运行。 |
| `@run-at` | 指定脚本的大致运行时机。 |
| `@grant` | 声明脚本使用的 Tampermonkey 特殊能力；`none` 表示不申请此类 API。 |

例如，`@match https://example.com/*` 表示匹配该网站下的路径。**匹配范围越宽，脚本能接触到的页面通常越多**，应与脚本功能相符。

## 八、修改、禁用和删除脚本

### 修改脚本

1. 打开 **Tampermonkey → 管理面板**。
2. 点击需要修改的脚本名称，进入编辑器。
3. 修改代码后按 **Ctrl+S** 保存。
4. 回到对应网页并刷新。

### 暂时禁用

在管理面板中找到脚本，关闭它旁边的启用开关，然后刷新网页。需要使用时可以再打开。

### 删除脚本

在管理面板找到脚本的删除按钮或菜单，确认删除。删除前如果以后还想使用，可以先复制代码保存为本地文本文件。

## 九、脚本不生效时怎么检查

按下面顺序排查：

1. **扩展是否启用：** Chrome 扩展程序中，Tampermonkey 是否已打开？
2. **脚本是否启用：** Tampermonkey 管理面板中，该脚本的开关是否打开？
3. **网站是否匹配：** 浏览器地址是否符合脚本的 `@match`？
4. **是否保存并刷新：** 编辑器修改后是否按了 Ctrl+S，网页是否刷新？
5. **脚本是否过期：** 网页更新后，旧脚本可能找不到原来的按钮或元素。
6. **是否存在多个脚本冲突：** 功能相近的多个脚本可能互相影响，可逐个禁用排查。
7. **查看控制台：** 在网页按 **F12**，打开 **控制台 / Console**，检查与脚本有关的报错。复制日志时不要包含密码、Cookie 或其他敏感信息。

如果脚本面板存在，但某个功能没有效果，也可能是脚本内部逻辑或网站播放器的兼容问题，不一定是 Tampermonkey 安装错误。

## 十、以雨课堂助手为例

如果要安装别人提供的雨课堂助手代码，可按以下流程：

1. 打开 Tampermonkey 管理面板，找到原来的“雨课堂刷课助手”；没有则新建。
2. 打开编辑器，**全选并替换为完整脚本**，按 **Ctrl+S**。
3. 返回雨课堂对应的视频页面，刷新。
4. 如果页面出现助手面板，检查版本号并按面板提示操作。

当前这次排查中的 **1.4 版助手自动设置倍速尚未可靠生效**。如果播放器菜单可以选择倍速，可先在播放器自己的菜单中手动调整；实际学习完成情况请以课程页面显示为准。
